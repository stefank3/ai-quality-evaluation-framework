# Roadmap

This milestone implements the deterministic evaluation foundation, optional guarded HTTP adapter, tests, reports and study material. It deliberately stops before real provider evaluation or deployment.

Potential future work, requiring separate scope and authorization:

- Broader synthetic adversarial cases with reviewed expected outcomes.
- Human annotation workflow for claim-level support and refusal quality.
- Statistical summaries for separately authorized repeated live runs.
- Additional adapter contracts if a concrete provider use case warrants them.
- Stronger OS-level network isolation when running untrusted components.

No distributed infrastructure, database, UI or model-as-judge is implied. Future ideas are not completed features and are not part of this milestone's validation evidence.
